Argonmine GPU 矿机 v1.0.1（Windows x64）
==========================================

单文件绿色版，只依赖 Windows 和 NVIDIA 显卡驱动。
不需要安装 CUDA Toolkit，也不需要 VC++ 运行库。

【第一次使用】

1. 打开 https://app.argonmine.com/ ，创建或恢复钱包。
2. 在 Receive（收款）页面复制你的地址，形如 arg1...。
   24 个助记词请离线保存，不要发给任何人。
3. 双击 argonmine-gpu.exe。
4. 按提示粘贴 arg1... 地址，回车。
5. 再输入 batch（显存）：1024 = 8 GiB，768 = 6 GiB，1536 = 12 GiB。
   直接回车用默认 1024。
   地址和 batch 会保存到同目录 argonmine-gpu.cfg，下次双击直接开始。

以后要改地址或显存：双击 setup.bat，按提示重新输入即可。
也可以直接编辑 argonmine-gpu.cfg：

    arg1你的地址...
    batch=1024

【停止】

按 Ctrl+C。等当前这批哈希算完就会停止。

【网页看板】

双击 dashboard.bat（需要 Python 3），浏览器会自动打开：
    http://127.0.0.1:8787/

- 手动输入你的算力（H/s / kH/s / MH/s），自动算全网占比、预计出块
- 添加多个 arg1... 地址，查看每个地址的余额、已挖、块数、成熟中、可花、最近出块
- 数据来自官方 explorer，每 5 秒刷新；只需要公开地址，不需要私钥
- 不需要矿机状态文件，矿机在别的机器上也能用
- 没有 Python 时，可以试直接双击 dashboard.html（浏览器能直连 explorer 时）

【24 小时运行 / 防断线】

- 矿机内置网络重试；找到块后提交失败会退避重试 6 次（约 31 秒）。
- 运行时系统不会睡眠；屏幕可以关闭。
- 想让它崩溃后自动重启：双击 watchdog.bat。
  第一次会提示输入地址并保存；之后每 5 秒检查一次，矿机退出就重启。
- 停止请双击 stop.bat，不要直接按 Ctrl+C（否则 watchdog 会重新拉起）。
- 建议插电、电源计划设为“从不睡眠”，网卡电源管理里取消“允许计算机关闭此设备以节约电源”，能用网线就用网线。
- 官方 work server 长时间挂了会一直重试但 GPU 空转；要彻底稳定可自建节点 + explorer，然后用 --url 指向本地。

【换地址】

删除或编辑 argonmine-gpu.cfg，或者用命令行：

    argonmine-gpu.exe --address arg1你的新地址...

【常用参数】

    --batch N       同时计算的哈希数，每个占 8 MiB 显存
                    默认 1024 = 8 GiB；显存不够会自动下调
    --ref arg1...   推荐人地址（可选）
    --duration N    运行 N 秒后自动停止
    --benchmark 10  只跑分，不联网、不提交
    --selftest      自检（含主网区块 652 的真实向量）
    --dry-run       取任务并计算，但不提交
    --help          查看全部参数

【注意】

- 如果 Windows SmartScreen 提示“未知发布者”，点“更多信息” → “仍要运行”。
  这是未签名程序的正常提示；源码就在项目目录，可自行编译核对。
- RTX 5070 12GB：建议 batch=1024（8 GiB）；不接显示器可试 1280（10 GiB）；
  不要用 1536，12 GiB 会被顶满并自动下调。
  RTX 50 系是 sm_120，原生编译需要 CUDA 12.8+；现成 exe 含 PTX，
  先运行 argonmine-gpu.exe --selftest --batch 512 验证能否被驱动 JIT。
- 温度：笔记本长时间挖矿会到 88-89°C 并触发温度墙降频。
  建议垫高机身、用散热垫、把风扇开到最大，或适当降低 --batch。
- 奖励：solo 挖矿，谁找到块谁拿奖励；奖励 100 个块后成熟。
- 官方 explorer 目前有一个重复扣 1% treasury 的 bug：
  浏览器矿机模板总额是 49.5 ARG 而不是 50，无推荐人时实际拿 49。
  程序会打印一次 warning，等官方修复后自动恢复正常。
- 本软件是第三方实现，与 Argonmine 项目方无关。
  挖矿消耗电力和硬件寿命，请自行评估风险。
